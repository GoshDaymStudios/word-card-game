# Screenshots / GIF for the README

Drop image files here and reference them from the main `README.md`. For a portfolio README,
a short **gameplay GIF** at the top converts best.

Suggested shots (record at desktop width for a clean nav row):
- `hero.png` — landing page (Cards & Words hero + Beta badge).
- `roguelike.png` — a run mid-game: tiles, modifier ("joker") cards, ante/target/score.
- `flip.gif` — guessing a word (the tile flip + sound is the signature moment).
- `leaderboard.png` — the mode-tabbed leaderboard.
- `themes.png` — the 3 palettes side by side (or a GIF of switching).

Tip: capture in the **Twilight** theme (default), unmuted, on a desktop-width window so the
nav shows on one line.
