# Screenshots / GIF for the README

Drop image files here and reference them from the main `README.md`. Capture at **desktop
width** (so the nav sits on one line), unmuted.

Priority order — the first one matters most:

1. **`gameplay.gif`** (hero, top of README) — type a guess and let the row flip, ideally with
   a skin switch from the ⚙️ menu at the end. The tile flip + the live skins are the signature
   moments; a short loop sells the project instantly.
2. **`roguelike.png`** — a run mid-game: tiles + the modifier ("joker") cards + the
   ante / target / score row. Shows the Balatro side.
3. **`daily.png`** — the Daily grid with some green/yellow tiles + the streak. Shows the
   Wordle side. (Classic skin.)
4. **`skin-dark.png`** — the same screen in a dark skin (e.g. Twilight) to show the theme
   range / juice next to the default Classic.
5. **`leaderboard.png`** (optional) — the mode-tabbed leaderboard.

Tip: stills 2–4 read best in the default **Classic** skin, with one dark-skin shot (4) for
contrast. A 5–8 second GIF beats a dozen stills.
